Cấu trúc cơ bản gồm có

1. Database : supabase.com hoạt động như một SQL Lite để lưu table Task 
Hỗ trợ chức năng tạo cột, import from csv , SQL querry command ....


2. Giao diện thao tác : CodeSpace của Github để tạo một app java jsx với cấu trúc 
a. App.jsx  : Giao diện chính
b. TaskModal : Subform thực hiện thao tác : NEW , EDIT 
c. TaskTable : hiển thị bảng dữ liệu dạng excel
d. Task Card : Giao diện phụ hiển thị dữ liệu dạng card cho mobile 

3. Lưu ý:
Title của Webpage được chỉnh ở file index.html





4. Cách lệnh thường dùng
a. Commit công việc đang làm để tạm dừng 

git add .
git commit -m "V0.7 Comment something"
git push


b. Tạo branch mới để lưu backup, nếu có lỗi thì quay lại cho dễ
git checkout -b version123

List of branch : git branch
Move về branch cũ: git checkout version123




c. Tạo tag  (verson) mới để dễ dàng quay lại cũng như để publish
git tag -a v0.7.Final -m "Production Release V0.7 Final"
git push origin v0.7.Final

d. Run chế độ dev
npm run dev

e. Build and Deploy app 
npm run build
npm run deply

f. Tổng hợp code cập nhật website
